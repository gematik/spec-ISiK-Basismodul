# Test Implementation Guide - Einführung

Willkommen zum Test Implementation Guide für die Validierung Ihrer lokalen FHIR IG Publisher Umgebung.

## Überblick

Dieses minimale Implementation Guide enthält:

- Grundlegende Konfigurationsdateien
- Eine einfache Einführungsseite
- Ein Test Patient Profil und Beispiel
- Ein Test CapabilityStatement
- Abhängigkeiten zu FHIR R4 Core

## Zweck

Dieses IG dient dazu zu testen, dass Ihre lokale FHIR IG Publisher Installation korrekt funktioniert. Wenn dieses IG erfolgreich erstellt wird, ist Ihre Umgebung ordnungsgemäß konfiguriert.

## Erste Schritte

Nach dem erfolgreichen Erstellen dieses Test-IG können Sie:

1. Eigene FHIR-Ressourcen hinzufügen
2. Profile und Erweiterungen erstellen
3. Zusätzliche Seiten und Dokumentation hinzufügen
4. Die Navigationsstruktur nach Ihren Bedürfnissen anpassen
