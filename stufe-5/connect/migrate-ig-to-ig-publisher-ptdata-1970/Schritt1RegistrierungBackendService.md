# Schritt 1: Registrierung eines SMART Backend Services

Die Registrierung eines SMART Backend Services erfolgt per “JSON Web Token (JWT) Profile for OAuth 2.0 Client Authentication and Authorization Grants”. Siehe . Dieser Schritt erfolgt einmal solange der durch den Client verwendete JSON Web Key nicht rotiert werden muss. Entsprechend wird auch für SMART Backend Services die Verwendung von JSON Web Key Sets empfohlen.
